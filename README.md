# Soundwave — Spotify Website Clone (DevCamp 2.0 Task 1)

A multi-page static music discovery website made with **HTML5 and CSS3 only**. No JavaScript or frameworks are used.

## Pages
- `index.html` — Home page with hero section, genre cards, featured playlists and footer.
- `browse.html` — Browse page with editor's pick, genre grid and popular playlists.
- `playlist.html` — Playlist details with cover art, metadata and a semantic track table.
- `login.html` — Optional sign-up page with required form inputs.

## Concepts demonstrated
- Semantic HTML: `header`, `nav`, `main`, `section`, `footer`
- External stylesheet: `style.css`
- Reusable class selectors and a unique ID selector
- Flexbox and CSS Grid layouts
- Box model spacing, padding, margins, borders and border radius
- Accessible image-role descriptions, form labels and `required` inputs
- Links connecting all pages
- Hover transitions on links, buttons and cards
- Consistent palette: green `#1DB954` and near-black `#191414`
- Responsive layouts for smaller screens

## Run locally
Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## GitHub submission
1. Create a new public repository named `spotify-website-clone` (or another name you prefer).
2. Upload all files from this folder, preserving the folder structure.
3. Commit the files and copy the repository URL for submission.

## Live deployment with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for the deployment to finish. Your site URL will be shown in the Pages section.

## Important
This is a **static educational clone inspired by music streaming layouts**, not an official Spotify product. The play control is intentionally visual only because the assignment prohibits JavaScript. The sign-up form is a front-end demo and does not submit or store account data.
